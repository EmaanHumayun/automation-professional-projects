# Assignment 01: Core Enhancement for Enterprise Automation and Integration Platform

### Objective
Extend the core automation with a dead-letter queue mechanism or rate-limiting filter.

### Requirements
1. Implement exponential backoff retry on failure.
2. Capture permanently failed jobs in a dead-letter queue.
3. Write an automated test verifying the retry mechanism.

### Rubric
- Code modularity: 30%
- Error handling: 40%
- Test coverage: 30%
